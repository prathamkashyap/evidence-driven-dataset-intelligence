# M4 Experiments — Content Evidence and Dataset Fingerprinting

## Overview

This directory contains empirical artifacts generated by Milestone 4 (`scripts/run_m4_fingerprint.py`) executing over the 10 canonical dataset records from M1 (`experiments/m1/results/development_corpus.jsonl`) and their associated M3 evidence ledger entries (`experiments/m3/results/evidence_ledger.jsonl`).

## Scope & Disclaimers

1. **Bounded sample observations, not whole-dataset truth:** All statistics (row count, feature count, word/char lengths, class counts, missingness) describe strictly the bounded sample ($\le 32$ records) inspected within the M0 empirical budget.
2. **Deterministic fingerprints, not recommendation scores:** M4 extracts structural and statistical characteristics without interpreting task suitability, predicting utility, or ranking datasets.
3. **Traceable provenance:** Every fingerprint embeds references to the originating M3 `LedgerEntry` IDs and preserves raw sample hashes.
4. **Explicit operational states:** Datasets that cannot be sampled due to access restrictions (Kaggle under M0 policy) or server errors (Beans HTTP 502) are explicitly recorded as `unsupported` or `failed` rather than discarded or fabricated.

## Generated Artifacts

- `results/dataset_fingerprints.jsonl`: 10 deterministic `DatasetFingerprint` records across tabular, text, image, unsupported, and failed states.
- `results/fingerprint_summary.json`: Aggregate modality breakdown, quality heuristic distributions, label diagnostic coverage, and runtime resource metrics (24.20 MiB peak RSS, well within the 128 MiB ceiling).
