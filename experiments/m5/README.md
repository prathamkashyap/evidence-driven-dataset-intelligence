# M5 Experiments — Task Utility Estimation & Baseline Ablation

## Overview

This directory contains empirical artifacts generated by Milestone 5 (`scripts/run_m5_utility.py`) evaluating the 10 canonical datasets from M1 (`experiments/m1/results/development_corpus.jsonl`) across 4 development reference tasks under three comparative baselines (120 total evaluations).

## Scope & Methodological Disclaimers

1. **Equal-Weight Linear Utility Baseline:** The scalar composite utility $U_{\text{baseline}}(D \mid T) = \sum_{k=1}^7 \frac{1}{7} u_k$ is an interpretable baseline formulation. It is **not** an optimal, learned, or universally true utility function.
2. **Development Reference Judgments, Not True Utility:** The 0–3 ordinal judgments in `tests/fixtures/m5_fixtures.json` are human-authored reference expectations created independently of the algorithm to provide an evaluation standard for development tasks. They do not represent real-world dataset quality or downstream model performance guarantees.
3. **Traceable Provenance:** Every estimate maintains an unbroken link to M3 evidence entries, M4 fingerprints, and task requirements.
4. **Categorical Uncertainty:** M5 uses structured categorical epistemic states (`known_favorable`, `known_unfavorable`, `unknown`, `unsupported`, `failed`, `conflicting`, `sample_limited_inference`) and evidence bases without assigning uncalibrated numerical confidence probabilities or uncertainty masses.

## Generated Artifacts

- `results/utility_estimates.jsonl`: 120 complete `TaskUtilityEstimate` records across all 4 tasks and 3 baselines.
- `results/baseline_ablation.json`: Quantitative comparative metrics (Spearman $\rho$, NDCG@3, NDCG@5, NDCG@10) across Baselines A, B, and C.
- `results/utility_summary.json`: Aggregate statistics, hard-gating counts, epistemic state distributions, and runtime metrics (24.67 MiB peak RSS, well within the 128 MiB ceiling).
